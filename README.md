# Počítadlo na vypracované otázky

## Ako používať
Poznámka: Návod je pre Eclipse IDE.
1) Stiahni si zdrojový kód a ikonku a importuj ich do projektu v Eclipse.
2) Vytvor si nejaký textový súbor na ukladanie počtu prejdených otázok.
3) Zisti, akú verziu Javy máš nainštalovanú cez menu štart.
4) V Eclipse klikni pravým tlačítkom na projekt, vyber Build Path -> Libraries a uisti sa, že verzia Javy vedená tam je rovnaká ako tá, ktorú máš nainštalovanú.
5) Klikni pravým tlačítkom na projekt a vyber Export -> Java -> Runnable JAR File.
6) V Library Handling vyber Package required libraries into generated JAR.
7) Hotovo :)
