# Počítadlo na vypracované otázky

## Ako používať
Poznámka: Návod je pre Eclipse IDE.
1) Stiahni si zdrojový kód a ikonku a importuj ich do projektu v Eclipse.
2) Vytvor si nejaký textový súbor na ukladanie počtu prejdených otázok.
3) Zmeň v Pocitadlo.java cesty k súboru na ukladanie počtu a k ikonke.
4) Zisti, akú verziu Javy máš nainštalovanú cez menu štart.
5) V Eclipse klikni pravým tlačítkom na projekt, vyber Build Path -> Libraries a uisti sa, že verzia Javy vedená tam je rovnaká ako tá, ktorú máš nainštalovanú.
6) Klikni pravým tlačítkom na projekt a vyber Export -> Java -> Runnable JAR File.
7) V Library Handling vyber Package required libraries into generated JAR.
8) Hotovo :)
